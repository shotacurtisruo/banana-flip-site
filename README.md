# Banana Flip — support & privacy

The two pages App Store Connect requires for [Banana Flip](https://apps.apple.com/app/id6821551941),
and nothing else. The game's source is not here.

- `privacy.html` — the privacy policy. Mirrors `docs/PRIVACY.md` in the game
  repo; change that one first, then regenerate this.
- `support.html` — the support page the App Store links to.

Served by GitHub Pages from `main`.
